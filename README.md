# Toprotein
# 🧬 Cancer vs Healthy Human PPI Network Comparative Analysis

A complete computational biology pipeline for constructing, analyzing, and visualizing **Protein-Protein Interaction (PPI) networks** using:

- Graph Theory
- Spectral Graph Analysis
- Topological Data Analysis (TDA)
- Persistent Homology
- Interactive Streamlit Visualization

The project compares:

- Cancer-associated human PPI networks
vs
- Healthy human PPI networks

to identify structural, spectral, and topological differences in biological interaction systems.

---

# 📌 Features

## ✅ Automated PPI Network Construction

Fetches protein interaction data directly from:

- IntAct PSICQUIC API

Builds:

- Cancer PPI network
- Healthy human PPI network

Exports:

- `.gml` graph files

---

## ✅ Spectral Graph Analysis

Computes:

- Adjacency spectrum
- Graph Laplacian spectrum
- Spectral radius
- Spectral gap
- Algebraic connectivity
- Eigenvalue distributions

Useful for studying:

- Network robustness
- Synchronization
- Signal propagation
- Modularity
- Diffusion dynamics

---

## ✅ Topological Data Analysis (TDA)

Uses persistent homology to analyze:

- Betti-0 connectivity
- Betti-1 cycles/loops
- Persistence entropy
- Significant topological features
- Structural complexity

Built with:

- Ripser
- Persim

---

## ✅ Interactive Streamlit Dashboard

Interactive frontend for:

- Network visualization
- Spectral comparison
- TDA comparison
- Eigenvalue exploration
- Betti curve analysis
- Comparative metrics

Includes:

- Plotly charts
- Interactive PyVis graph explorer
- Real-time comparative statistics

---

# 🧠 Scientific Motivation

Cancer rewires cellular signaling pathways and protein interactions.

This project investigates whether cancer-associated protein interaction networks differ from healthy networks in terms of:

- Connectivity
- Spectral behavior
- Topological persistence
- Structural complexity
- Network robustness
- Information flow

using modern graph-theoretic and topological techniques.
